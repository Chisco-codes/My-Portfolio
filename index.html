The Problem

People have no real-time awareness of their mental state while working. Focus drifts, fatigue builds — but there's no feedback loop. I wanted to solve that with AI running entirely in the browser.

Solo developer — designed system architecture, integrated TensorFlow.js and MediaPipe models, built the conversational AI layer (Aria), deployed as PWA.

Running computer vision at 30fps without blocking the UI thread. Solved by throttling landmark processing to match display refresh rate, reducing CPU load significantly.

04 — Personal AI System

ChiscoAI

My second brain. An AI system built to know me, think alongside me, and accelerate everything I do.

🧠 Personal AI System — Active Build

ChiscoAI

// second_brain.py — always running · real-time research enabled

v0.4.0-dev
Streamlit Interface
● real-time data active

ChiscoAI is not another chatbot. It's a personal AI system built around how I specifically think, learn, and build. It started as a terminal interface and has evolved into a Streamlit-powered application with a full surface — now capable of real-time web research, persistent memory across sessions, and behavioral coaching based on documented patterns of how I operate under pressure, focus, or overwhelm.

The architecture is built on LangChain as the backbone — handling memory chains, tool use, and LLM orchestration. Streamlit provides the interface. Every response is filtered through documented behavioral rules, personality constraints, and drift-correction logic stored in a structured memory file system. ChiscoAI knows when I'm overwhelmed and gives me one action, not five. That's the kind of AI intelligence that matters.

🧠 Persistent Memory System
14 structured memory files tracking behavioral patterns, emotional state, philosophy, goals, reflections, and response rules — across every session.
🌐 Real-Time Research
Integrated web access — ChiscoAI can search, retrieve, and synthesize current information to support decisions and learning in real time.
🔄 Drift Correction
Monitors its own response patterns. When behavior drifts from documented rules — it self-corrects. A system with a philosophy it enforces.
🛠️ Build Companion
Reviews code, suggests architecture, helps debug — with full context of every project I'm working on and why. No starting from scratch every session.

05 — Open Source I Use

Open Modules

The frameworks and models I've integrated — and what I've actually done with them beyond the defaults.

LangChain
AI Framework

The backbone of ChiscoAI. LangChain orchestrates the entire AI pipeline — memory chains, tool routing, LLM calls, and context management across sessions. It's what makes ChiscoAI a system, not just a chatbot.

How I use it
Memory chain management → LLM orchestration → tool use → real-time web search integration
TensorFlow.js
ML Framework

Google's open-source ML library running in JavaScript. I use it to run pre-trained neural networks for face detection and emotion classification directly in the browser — no server, no latency.

My optimization
Async processing pipeline — landmark detection throttled to display refresh rate, preventing UI thread blocking
MediaPipe
CV Framework

Google's real-time computer vision framework. I use the Face Landmarker model — 478 3D landmarks per frame — to track eye openness, gaze direction, and micro-expressions in real time.

My integration
478-point face mesh → eye aspect ratio calculation → fatigue score → LLM context injection
Streamlit
UI Framework

Python-native UI framework. I use it to build ChiscoAI's interface — evolving from a terminal-only tool into a full visual application with a proper surface for interaction, memory visualization, and session management.

Current use
ChiscoAI full interface — chat surface, memory viewer, real-time research display, session control
